# Paula Bandeira — Site institucional

Novo site institucional de Paula Bandeira, Neuropsicopedagoga, preparado para GitHub Pages.

## Estrutura
- `index.html` — página principal
- `assets/styles.css` — identidade visual e responsividade
- `assets/script.js` — menu, efeitos e interações
- `assets/logo.png` — logomarca otimizada para web
- `assets/favicon.svg` — favicon
- `CNAME` — domínio `paulabandeira.com.br`
- `robots.txt` e `sitemap.xml` — SEO básico

## Publicação
Em `Settings > Pages`, selecionar `Deploy from a branch`, branch `main`, pasta `/ (root)` e salvar.

## Observação de conteúdo
Confirmar a situação final da Licenciatura em Pedagogia, anteriormente indicada com previsão de conclusão em novembro de 2024.
